# Node AI — landing page

Single-file landing page for Node AI (`index.html`), built with Tailwind CSS (CDN), Lucide icons and vanilla JavaScript.

## Structure
- `index.html` — the whole site (markup, styles, scripts)
- `assets/nodeailogo.svg` — Node AI logo

## Before launch
- Replace links in the `LINKS` object at the top of the script (web app, App Store, Google Play, QR target).
- Replace placeholder stats (search for `TODO: replace placeholder`).
- Replace `.img-slot` placeholders in the "Discover what Node AI can do" section with real images.

## Hosting on GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
